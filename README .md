# Elam Mtshwane: Digital Portfolio

Digital portfolio for **Project Presentation 3 (PRP371S)** at the Cape Peninsula University of Technology, built as a GitHub Pages site.

It documents my Agile evidence for the Entrepreneurial WIL project, **eKhaya Connect**: an affordable, community-owned wireless internet service for Khayelitsha.

## Contents

- **About**: study, skills and WIL placement goals
- **Project**: problem, community research, brand and solution overview
- **Charter**: project charter
- **User Stories**: stories for the service and app
- **Product Backlog**: 16 cards across 4 sprints (Trello)
- **Sprint Backlog**: work planned and completed per sprint
- **Agile Logbook**: reflections and progress log
- **References**: Harvard-style reference list

## Viewing the portfolio

- **Online:** open the GitHub Pages link for this repository.
- **Locally:** download `index.html` and open it in any browser. No build step or dependencies are needed.

## Publishing on GitHub Pages

1. Put `index.html` in the root of the repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. The site is live at `https://<username>.github.io/<repository>/` after a minute or two.
